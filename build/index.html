The Pathway Streaming Engine

VitalX uses two Pathway-based microservices that act as the core brain of the system, converting raw telemetry into actionable clinical intelligence.

01

Microservice #1

Real-Time Feature Engineering

Consumes raw vitals from Kafka and computes derived medical indicators used by the ML model.

Computed Features:

  • • Shock Index (HR / SBP) — circulatory stability indicator
  • • Mean Arterial Pressure (MAP) — perfusion adequacy
  • • Pulse Pressure — cardiac output proxy
  • • Rolling averages — trend baselines (60s windows)
  • • Rate-of-change signals — deterioration velocity
  • • Vital trend detection — anomaly flagging
Pathway Advantage

Incremental computation — metrics update instantly when new data arrives, enabling sub-100ms latency even at 120 vitals/second.

Output Stream:
Kafka → vitals_enriched
02

Microservice #2

Live Streaming RAG Engine

Powers real-time Retrieval-Augmented Generation (RAG) by converting live patient data into contextual knowledge.

Streaming RAG Pipeline:

1
Patient vitals ingestion (Kafka)
2
Context formatting (NL text generation)
3
Embedding generation (sentence-transformers)
4
Vector indexing (auto-updating KNN)
5
LLM reasoning (contextual answers)
Streaming RAG Advantage

Unlike static RAG systems, Pathway auto-updates embeddings as new vitals stream in — no batch reindexing required. Fresh context in 1-2 seconds.

Clinical Query Example:
"Why is Patient P003 high-risk?"
→ AI retrieves last 3 hours of vitals + generates contextual explanation
# Pathway Streaming Logic (Feature Engineering)
table = pw.io.kafka.read(config, topic="vitals_raw")
vitals = table.select(
shock_index = pw.this.hr / pw.this.sbp,
map = (pw.this.sbp + 2 * pw.this.dbp) / 3,
trend_30m = pw.reducers.avg(pw.this.hr)
)
# Output to enriched stream
pw.io.kafka.write(vitals, topic="vitals_enriched")
# Parallel RAG indexing
rag_store = VectorStoreServer(vitals, embedder=embedder)

Why Two Separate Pipelines?

Independent Scaling

Feature engineering (CPU-bound) and RAG (memory-bound) scale separately

Failure Isolation

If LLM API fails, vital processing continues uninterrupted

Reusability

Enriched vitals feed ML service, alert system, and RAG simultaneously

VitalX Analysis

Patient ICU-003 exhibits a worsening trend in several critical parameters:

  • Shock Index: Increased from 0.72 → 1.08 over the last 90 minutes (critical threshold >1.0)
  • Mean Arterial Pressure: Downward trend, currently 64 mmHg (target: 65-100 mmHg)
  • Temperature: Spiked to 38.6°C (101.4°F) with concurrent HR increase to 112 BPM
  • Lactate: Elevated at 3.2 mmol/L (normal <2.0) indicating tissue hypoperfusion

Recommendation: Immediate clinical assessment. Consider serum lactate re-check, blood cultures, and initiation of Sepsis-3 protocol. Fluid resuscitation may be warranted.

What should I do RIGHT NOW?
Urgent Action Plan
  1. 1. Notify attending physician immediately — escalate to rapid response if available
  2. 2. Obtain blood cultures before antibiotics (2 sets from different sites)
  3. 3. Check lactate and blood gas to assess metabolic status
